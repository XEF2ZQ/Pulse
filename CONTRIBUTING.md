# Feedback and contributions

Pulse currently publishes its source for technical and portfolio review under an all-rights-reserved notice. It is not an open-source-licensed project.

Use repository issues for reproducible bug reports or design discussion. Include the source/release version, Windows build, CPU model, power source, expected/actual behavior and a minimal reproduction. Remove personal paths, serial numbers, account details and unrelated process data from reports.

Before submitting code or documentation for incorporation, open an issue to agree on scope and explicit contribution rights. Do not assume this repository's notice transfers your copyright to the project owner or grants permission to reuse its code. No automatic contributor licence agreement is implied.

Changes affecting power ownership need native readback and restoration evidence. Classification changes need false-positive cases for media/voice alongside productive workloads. Scheduling or hardware tuning proposals need measured benefit and reversible failure handling. Unit tests alone cannot establish battery savings.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md).
